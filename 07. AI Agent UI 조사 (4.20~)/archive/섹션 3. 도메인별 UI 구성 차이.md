의견: 도메인별 차이보다는 아키타입을 정의하는것이 나을지도? 도메인이 같아도 서비스마다 너무 달라서


20개 이상의 글로벌 AI 제품을 분석한 결과, 순수 챗봇 중심 UI는 예외에 가깝습니다. 압도적 다수는 **워크플로우 임베드형** — 즉, 사용자가 이미 쓰고 있는 도구(EHR, IDE, CRM, .docx 편집기) 안에 AI가 스며드는 형태입니다. 대화 창은 우측 사이드 패널, 반짝이는 스파클 아이콘 메뉴, 또는 커맨드 바로 축소되고, **진짜 주인공은 도메인 특화 결과물(artifact)** 입니다.

---

## UI 아키타입 3가지 정의

분류 기준을 먼저 고정합니다.

| 아키타입                  | 정의                                           | 특징                              |
| --------------------- | -------------------------------------------- | ------------------------------- |
| **Chat-first**        | 대화 스레드가 주요 화면이며 기본 진입점                       | 인용, 표, diff 등이 대화 버블 내에 임베드     |
| **Dashboard-first**   | 데이터 시각화·표·KPI 타일이 화면 중심                      | 채팅은 사이드 패널 또는 별도 탭              |
| **Workflow-embedded** | AI 전용 화면 없음. 기존 도구에 스파클 아이콘·사이드바·컨텍스트 메뉴로 삽입 | Abridge, Ironclad, ServiceNow 등 |

많은 제품이 아키타입을 혼합하며, 보고서에서는 혼합형도 명시합니다.

---

## 도메인 1. 금융/투자 — Dashboard-first + AI 사이드카

금융은 챗봇이 가장 명확하게 거부되는 도메인입니다. 모든 전문가용 금융 제품은 구조화된 데이터 워크스테이션을 중심에 두고, AI를 사이드 패널로 붙입니다. 이는 숫자마다 출처를 밝혀야 하는 수탁 책임과, 결과물이 결국 Excel로 내보내지는 워크플로우에서 기인합니다.

**Bloomberg ASKB (2026년 베타 출시)** 기존 Terminal의 4분할 커맨드 UI에 대화 패널을 추가한 형태. 응답에는 주석이 달린 차트, 블룸버그 뉴스·리서치 인용, Excel/BQuant 내보내기용 **BQL 코드 블록**, 그리고 저장 가능한 **ASKB Workflow**(실적 발표 전후 준비, 고객 미팅 준비 등 멀티스텝 템플릿)가 포함됩니다. 분류: **워크플로우 임베드형 챗** (Dashboard-first 제품 위에 얹힘)

**AlphaSense** 왼쪽 사이드바(대시보드·검색·생성 검색·Generative Grid), 가운데 문서 뷰어(키워드 하이라이팅), 생성된 모든 문장에 인라인 인용. 핵심 기능인 **Generative Grid**는 행=문서, 열=자연어 프롬프트인 스프레드시트로, 수십 개의 10-K나 실적 발표를 한 화면에서 비교합니다. 분류: **Dashboard-first + 생성형 그리드**

**Valley AI (valley.town) — 한국 시장 직접 레퍼런스** 채팅 인터페이스가 **전혀 없습니다**. 상단 내비게이션 4개(커뮤니티, 예측대회, 투자분석, 아카데미)와 투자분석 허브의 **30개 이상 구조화 도구** (섹터 히트맵, DCF/RIM/DDM 밸류에이션 빌더, Reverse DCF, 구루 13F 포트폴리오, 재무제표 비교표, 예측대회 Valley Polls 등)로 구성됩니다. 한국 리테일 투자 시장에서 채팅 없이도 성공한 사례로, **구조화 툴링 + 커뮤니티가 대화형 AI를 이길 수 있음**을 보여주는 중요한 증거입니다. 분류: **Dashboard-first / 툴 스위트 (챗 없음)**

**금융 도메인 고유 UI 컴포넌트** 재무제표 표준 테이블, DCF/RIM/DDM 모델 폼, 상대가치 히트맵, 종목 스크리너 필터 빌더, 구루 포트폴리오 오버레이, 실적 캘린더, 10-K 주석 레이어, Generative Grid, BQL 코드 블록, **문장 단위 클릭 가능 인용 (1차 출처 연결이 필수)**

## 도메인 2. 법률 — 문서 + 챗 듀얼 패널, 레드라인이 출력 형식

법률 AI는 하나의 패턴으로 수렴합니다. 문서/결과물 캔버스가 화면 중심, 오른쪽에 채팅·프롬프트 패널, 인용·추론 패널이 인라인 또는 인접 배치. 신뢰 기준이 극도로 높아, 모든 제품이 번호가 달린 인라인 인용과 출처 하이라이팅을 전면에 내세웁니다.

**Harvey AI** 왼쪽 사이드바(Assistant, Vault, Workflow Agents, Knowledge, History). Assistant는 채팅 컴포저 + 오른쪽 번호형 클릭 가능 인용 패널. **Vault**는 행=문서, 열=추출 데이터 포인트인 스프레드시트형 **Review Table**로 각 셀에 검증 플래그와 인용 링크가 붙습니다. Harvey 디자인팀이 공개한 원칙: _"AI가 적용한 논리를 사용자가 역추적할 수 있는 명확한 페이퍼 트레일을 제공한다. 우리 플랫폼은 블랙박스가 아니다."_ 분류: **워크플로우 임베드형 (채팅이 진입점, 실제 작업은 Vault 테이블·Workflow Agent)**

**Thomson Reuters CoCounsel** **Skill 갤러리**(법률 리서치 메모, 문서 검토, 계약 정책 준수, 타임라인 생성 등 타일 선택 방식)에 에이전트형 **Guided Workflow**(미리 보기 가능한 리서치 플랜)가 추가된 형태. 빈 프롬프트 대신 Skill 타일로 진입하는 것이 특징입니다. 분류: **Dashboard-first / 태스크 갤러리**

**Ironclad AI (Jurist)** 3분할 워크스페이스: 왼쪽 **Logs 패널**(모든 에이전트 액션을 자연어로 기록), 가운데 **네이티브 .docx 에디터**(AI·사용자·제3자를 색상 코딩한 Track-Changes 레드라인), 오른쪽 채팅 패널. CPO 발언: _"브라우저 안에 .docx 네이티브 Word 환경을 그대로 내장했다. 다른 AI 도구들은 이 두 가지가 완전히 분리돼 있다."_ 분류: **워크플로우 임베드형 / 문서 우선**

**법률 도메인 고유 UI 컴포넌트** Review Table, 색상 코딩 Track-Changes 레드라인, 번호형 인용 + 출처 구절 미리보기, Playbook 패널(추천 조항 편집 목록), Skill/Workflow 갤러리, 관할권 선택기, 의뢰인 번호 입력, 가시적 추론 단계 트레일. **Word 네이티브 통합은 기본 전제** — 모든 제품이 Word 애드인 또는 브라우저 내장 .docx 에디터를 제공합니다.

## 도메인 3. 의료 — 주변 음성 수집 + 증거 연결 노트, 챗 없음

의료 AI는 가장 깔끔한 아키타입을 보여줍니다. **녹음 버튼이 주요 UI 어포던스**, 이어서 모든 문장이 오디오 타임스탬프에 연결된 편집 가능한 SOAP 구조 노트 초안이 뒤따릅니다. 채팅은 사실상 없습니다.

**Abridge** Epic **Haiku**(모바일 녹음) → Epic **Hyperdrive** 노트 컴포저(노트 초안 착지 + 의사 증언 필요) 형태로 Epic에 직접 내장. 핵심 UI는 **Linked Evidence** — 초안 노트의 어느 문장을 클릭해도 해당 정보가 언급된 정확한 트랜스크립트 구간과 오디오 타임스탬프가 하이라이팅됩니다. 분류: **워크플로우 임베드형** (녹음 버튼 누르기 전까지 AI는 비가시적)

**Nabla** 크롬 확장 또는 웹 오버레이로 작동하는 경량 오른쪽 패널. 녹음 버튼 + 실시간 트랜스크립트. **신뢰도 음영** — 의료 ASR이 용어를 검증하면 텍스트가 밝은 색에서 진한 색으로 변합니다. **Magic Edit** 커맨드 박스(자연어로 노트 수정 지시)가 유일한 챗 유사 어포던스. 분류: **워크플로우 임베드형 사이드 패널 코파일럿**

**의료 도메인 고유 UI 컴포넌트** 단일 탭 녹음 버튼, 신뢰도 음영 실시간 트랜스크립트, SOAP 구조 편집 가능 노트 초안, Linked Evidence 오디오 하이퍼링크, ICD-10/문제 목록 제안 + 청구 코드 그룹화, 전문과 템플릿 선택기, **EHR 딥 임베딩이 지배적 배포 모델** (Epic Haiku/Hyperdrive/Rover, Oracle Health)

## 도메인 4. 제조/품질 — IDE + 대시보드, AI는 오버레이

제조는 의료와 유사하게 챗을 거부하지만, 결과물은 임상 노트가 아닌 이미지 또는 공장 디지털 트윈입니다.

**Landing AI LandingLens** 프로젝트 유형별(분류, 객체 탐지, 분할, 이상 탐지) 클라우드 MLOps 워크벤치. 핵심 루프: **라벨 → 훈련 → 배포**. 가운데 이미지 뷰어(바운딩 박스·폴리곤·픽셀 마스크 그리기), 사이드 패널(IOU 점수 표시 모델 훈련 타일), 신뢰도 임계값 슬라이더가 있는 혼동 행렬, LandingEdge로 원클릭 내보내기. 분류: **Dashboard-first / MLOps IDE**

**Sight Machine** 공장 디지털 트윈 위의 역할 기반 BI 대시보드. 핵심 화면은 국가·공장·기계·계약 제조사별 필터링이 가능한 **Global Ops View**. 역할별 뷰(플랜트 매니저용 실시간 라인 현황, 공정 엔지니어용 SPC 차트·다운타임 파레토, 운영자용 황금 실행 목표)가 레이어로 추가됩니다. 신규 **Sight Machine Build** 에이전트는 자연어 프롬프트를 맞춤형 분석 앱으로 변환합니다. 분류: **Dashboard-first + 에이전트 레이어(신규)**

**제조 도메인 고유 UI 컴포넌트** 바운딩 박스·폴리곤 어노테이션 도구, 불량 부위 히트맵 오버레이, 런타임 임계값 슬라이더가 있는 혼동 행렬, Ground-Truth vs. 예측 이중 오버레이, OEE/수율/사이클 타임 KPI 타일, 다운타임 파레토 + 작업자 원인 코드 확인, 디지털 트윈 공정 흐름, SPC 추세 차트, **OT 통합 (PLC Ethernet/IP, OPC-UA, MES/SCADA 커넥터)**

## 도메인 5. 소프트웨어 개발 — 가장 빠르게 진화 중, 에이전트 워크스페이스로 전환

코딩은 UI 실험이 가장 활발하고 아키타입 변화가 가장 빠릅니다. 방향은 명확합니다.

> **자동완성(2022) → IDE 내 챗(2023~2024) → 컴포저/에이전트 패널(2024~2025) → 에이전트 조율 워크스페이스(2025~2026)**

**Cursor** VS Code 포크. v0.40에서 채팅과 컴포저를 단일 Agent 패널로 통합, Cursor 3에서 에이전트를 병렬 실행하는 타일 레이아웃 도입. 주요 컴포넌트: Tab 자동완성 고스트 텍스트, Cmd+K 인라인 플로팅 프롬프트, 파일별 수락/거부가 가능한 멀티파일 Composer 차이, 병렬 세션용 Agents Window. 분류: **에이전트 워크스페이스 (IDE 포크)**

**GitHub Copilot Workspace** 좌→우 흐름의 편집 가능한 스펙-플랜 아티팩트 파이프라인: **Task → Specification → Plan → Implementation → Diff → PR**. 스펙은 편집 가능한 두 개의 불릿 리스트(현재 상태 vs. 목표 상태), 플랜은 파일별 액션 목록, 모든 단계가 편집·재생성·취소 가능. 분류: **Human-in-the-loop 체크포인트 편집형 워크스페이스**

**Devin (Cognition AI)** 지금은 업계 표준이 된 **4분할 에이전트 데스크**: 왼쪽 채팅/세션 패널 + 오른쪽 Planner·Shell·Browser·Editor 탭 워크스페이스. Devin이 사용 중인 도구로 패널이 자동 전환되는 "Following" 토글, 전체 세션을 스크럽할 수 있는 **Timelapse** 포함. 분류: **에이전트 조율 워크스페이스 (사용자는 관찰자)**

**Claude Code** 반대편 극단의 미니멀리즘 — **터미널 TUI**가 주요 인터페이스. 하단 Task Pill이 병렬 서브에이전트 상태 표시, StructuredDiff 컴포넌트가 터미널 내 리치 diff 렌더링. 분류: **워크플로우 임베드형 (기존 스택 강화)**

**개발 도메인 고유 UI 컴포넌트** 고스트 텍스트 자동완성, 인라인 플로팅 프롬프트 박스, 변경 단위 수락/거부가 가능한 멀티파일 diff 뷰, 편집 가능한 스펙/플랜 불릿 트리, Todo 트리, Shell/Browser/Editor 뷰포트, 세션 리플레이 타임라인, 탭 형태의 병렬 에이전트 세션, 슬래시 커맨드, @-멘션 파일/라인 컨텍스트

## 도메인 6. 고객 서비스/엔터프라이즈 — 항상 두 개의 UI

고객 서비스는 모든 제품에 두 가지 전용 UI가 공존하는 유일한 도메인입니다. **최종 사용자용 Chat-first + 상담원/관리자용 Workflow-embedded**. 한국 기업 AI 제품도 이 두 트랙을 처음부터 계획해야 합니다.

**Intercom Fin** 최종 사용자 채팅 위젯(Fin Messenger) + 상담원용 Intercom Inbox(3분할 워크스페이스, AI 해결 상태별 폴더). **Fin AI Copilot**은 ⌘/Ctrl+K로 호출하는 오른쪽 사이드바 탭으로, 인용 출처를 노란색 하이라이팅으로 표시하고 "composer에 추가" 또는 "수정 후 추가" 버튼 제공. 배포 전 QA용 **Simulation/Preview/Batch Test** 하네스 보유. 분류: **고객용 Chat-first + 상담원용 Workflow-embedded 코파일럿**

**Salesforce Agentforce** **Agentforce Builder**(자연어 Canvas 뷰 + Agent Script 언어의 Script 뷰)에서 복잡성 대부분을 처리. 런타임에서는 AI가 전용 채팅 인박스가 아닌 **표준 Service Cloud Case 레코드 레이아웃** 내 임베드 위젯으로 출현합니다. 분류: **워크플로우 임베드형 (CRM 레코드 내장)**

**ServiceNow Now Assist** 에이전트 측 패턴이 가장 독특합니다. Service Operations Workspace 우측 상단의 **스파클 아이콘 ✨** 클릭 → **Now Assist Panel**(최근 릴리스에서 크기 조정 가능한 자유 부동 Dynamic Window로 업그레이드). **NAcm(Now Assist Context Menu)** 컴포넌트가 특정 필드에 AI를 임베드합니다. 거버넌스 레이어로 **AI Control Tower** — AI 인벤토리·승인·성능 추적을 위한 별도 대시보드. 분류: **워크플로우 임베드형 스파클 코파일럿 + 거버넌스 대시보드**

**고객 서비스 도메인 고유 UI 컴포넌트** "담당자에게 연결 중" 상태가 명시된 채팅 위젯, AI 해결 상태별 필터링 Inbox 폴더, 해결률 KPI 대시보드, 노란색 출처 하이라이팅 + composer 삽입 버튼의 코파일럿 패널, 스파클 아이콘 진입점, Canvas + Script 모드의 자연어 로우코드 에이전트 빌더, Preview/Simulation/Batch Test 하네스, **별도 거버넌스/Control Tower 대시보드**

## S-Core 기획 시사점 3가지

**① 결과물(Artifact)이 제품이다, 채팅이 아니라.** 금융은 밸류에이션 모델, 법률은 레드라인이 달린 .docx, 의료는 Epic 내장 SOAP 노트, 제조는 라벨링된 이미지와 OEE 대시보드, 코딩은 편집 가능한 diff와 스펙 트리, 고객 서비스는 감사 트레일이 있는 해결된 티켓을 각각 제품의 핵심으로 삼습니다. Valley AI가 채팅 없이도 한국 리테일 투자 시장에서 성공한 것은 이 원칙을 로컬 컨텍스트에서 검증한 사례입니다.

**② 신뢰 UI는 선택이 아닌 필수다.** 모든 도메인이 동일한 세 가지로 수렴합니다 — 출처 구절로 연결되는 인라인 인용, 가시적 추론/사고 단계 트레일, AI 출력에 대한 명시적 수락/거부 게이트(법률의 Track-Changes, 코딩의 Diff, 의료의 Linked Evidence, 금융의 클릭 가능 출처, 고객 서비스의 insert-to-composer). 금융위 컴플라이언스, 의료법, 개인정보보호법 등 한국 규제 환경의 엔터프라이즈 고객에게는 이 어포던스가 기본 전제 조건입니다.

**③ 스파클 아이콘 우측 패널 코파일럿이 엔터프라이즈 표준으로 굳어지고 있다.** ServiceNow의 스파클 진입점, Intercom의 Copilot 탭, Salesforce의 Assistant 패널, Harvey의 Assistant 모드, Cursor의 Agent 패널 — 동일한 디자인 언어가 도메인을 가로질러 결정화되고 있습니다. 이 패턴은 자연스럽게 두 가지와 짝을 이룹니다: **Preview/Simulation/Batch Test 하네스**를 갖춘 자연어 로우코드 빌더(Agentforce, Fin, ServiceNow), 그리고 빌더와 분리된 **거버넌스 대시보드**(ServiceNow AI Control Tower, Agentforce Testing Center). 이 세 가지 화면(런타임 코파일럿 + 빌더 + 컨트롤 타워)은 앞으로 모든 진지한 엔터프라이즈 AI 제품의 표준 틀이 될 가능성이 높습니다.
