**버티컬 에이전트**
특정 산업의 특정 업무에 특화된 에이전트 / ex) 우리은행 AI Compliance

**목적**
어떤 업무를 버티컬 에이전트에 적합하다고 판단할 것인지
나중에는 RFP 수용 여부나 자산화할 에이전트를 선정할때도 활용할 수 있도록 고도화?

**이거 안되면 탈락**
- 에이전틱함: 챗봇으로 축소되지 않는 업무 → 판단/도구 호출/멀티스텝이 있는가
- 출력 검증 가능성: 출력이 맞았는지 틀렸는지 판단 또는 합의할 기준이 있는가
	- 예를 들면 마케팅 카피 생성 에이전트는 탈락
- 효과 측정 가능성: 전/후 비교할 정량적 지표가 명확한가
	- but, 명확한 정량 지표는 없더라도 리스크 감소나 규제 대응같은 것은 니즈가 있어보임

**우선순위 조건**
1. 데모 난이도
	- 한 화면/짧은 시나리오(5분?)에서 "이거 다르네"가 전달되는가
	- 시연만 해도 전달 >> 결과물은 인상적이지만 설명이 필요 >> 화면을 말로 해석해야지만 전달됨
2. 중복 판매 가능성 (컨사 피드백 필요)
	- 여러 고객사에 팔 수 있나 / 업계 특수성은 있지만 구조는 비슷한가
	- 전자 DX 필드 디스크립션 에이전트 >> 한 고객사에만 있는 고유 프로세스
3. 개발 난이도 대비 효과
	- 프로토타입 수준으로 가치전달 가능한지/풀스택 구현 없이도 핵심이 보이는지
