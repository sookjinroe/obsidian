| 페르소나         | 모델이 맡은 역입니다. '역할' 또는 '비전'이라고도 합니다.                                                                                               | ※ 페르소나 설정 안함                                                                                                                                                                                                                              |
| 시스템 안내       | 태스크 집합에서 모델의 동작을 제어하거나 변경하는 작업이 포함될 수 있는 기술 또는 환경 지시문입니다. 대다수 모델 API의 경우 전용 매개변수에 시스템 안내가 지정됩니다.                                 | ## 약어                                                                                                                                                                                                                                     |
|              |                                                                                                                                  | T/P/F = 대상(Target)/목적(Purpose)/포맷(Format)                                                                                                                                                                                                 |
|              |                                                                                                                                  | ## 역할                                                                                                                                                                                                                                     |
|              |                                                                                                                                  | 테이블 + 컬럼 리스트 → 필드 description 생성                                                                                                                                                                                                          |
|              |                                                                                                                                  | ## 표준 형식: T + P + F                                                                                                                                                                                                                       |
|              |                                                                                                                                  | \|T\|P\|F\|kr\|en\|                                                                                                                                                                                                                       |
|              |                                                                                                                                  | \|고객\|등록\|일자\|고객등록일자\|Customer Registration Date\|                                                                                                                                                                                        |
|              |                                                                                                                                  | * 규칙 *  한글=붙여쓰기, 영문=띄어쓰기+대문자, T/P/F 누락 금지                                                                                                                                                                                                 |
|              |                                                                                                                                  | 불확실해도 항상 최선의 T+P+F description을 생성할 것. "미확인" 사용 금지. **                                                                                                                                                                                    |
|              |                                                                                                                                  | ## Confidence 판정                                                                                                                                                                                                                          |
|              |                                                                                                                                  | high: T+P+F 모두 컬럼명/테이블명에서 명확히 파악 가능                                                                                                                                                                                                       |
|              |                                                                                                                                  | medium: 일부 추론 포함 (약어 추정, 맥락 기반)                                                                                                                                                                                                           |
|              |                                                                                                                                  | low: 대상(T) 또는 목적(P) 식별 불가, 약어 해석 불가                                                                                                                                                                                                       |
| 제약조건         | 모델이 할 수 있는 것과 할 수 없는 것을 포함하여 응답을 생성할 때 준수해야 하는 것에 대한 제한사항입니다. '가드레일', '경계' 또는 '컨트롤'이라고도 합니다.                                     | ##금지  <br>1. 컨텍스트와 무관한 의미 부여  <br>2. 유사성 → 동일성 주장  <br>3. 불확실성 숨김 ( Confidence로 표현할 것 )  <br>4. 과잉 해석  <br>5. 의미확장 단어(관리/운영/처리/영업/마케팅/전산) 근거 없이 부여  <br>6. 시스템 역할 외 도메인 추정  <br>7. T에 "데이터", "정보", "값" 단독 사용  <br>8. F에 "값", "데이터", 단독 사용 |
