# 제안 흐름 (피드백 반영 최종본)

## 1. 제안 목적 및 배경

**핵심 논지:** 본 과제의 성공은 단순한 "AI 도입"이 아니라, **"AI를 통한 ITO 운영 효율화의 객관적 증명"** 에 달려 있다.

**이 장에 담을 내용:**
- 과제 배경 (RFP 기반): 전사 8대 프로세스를 지원하는 업무시스템의 단순/반복 ITO 운영업무를 AI로 개선
- 과제 위상: 1·2차를 통해 기개발 Agent 7종 확보, 본 3차 과제는 **고도화 + 신규 확대 + 무인화 + 성과측정**을 통합 수행
- 우리의 이해: 본 과제는 Agent 개수를 늘리는 과제가 아니라, Agent를 **연계·확대·증명**하여 ITO 운영의 새로운 표준을 만드는 과제

> **[근거]**
> - RFP Ⅰ. 개요
> - RFP 별첨 1 평가항목 (기개발 Agent 고도화, 신규 Agent 개발, MCP Agent 연계, 무인화 시범운영, 성과측정 및 계약연계)
> - RFP 3.1~3.5 추진전략

---

## 2. 제안 범위
**핵심 논지:** 본 과제를 통해 삼성전자에 다음 7가지 산출물을 운영 가능한 형태로 제공한다.

**제공 산출물:**

**① 고도화된 기개발 Agent 7종**
- 개발 단계: 요구사항 정의, 분석/설계, 코딩, 테스트 시나리오 생성
- 운영 단계: 화면 모니터링, 시스템 모니터링, 이상상황 조치가이드

**② 신규 개발 Agent**
- 운영 영역 확대 (보안점검, 배포관리 등)
- 솔루션 특화 Agent (ABAP, SFDC, Workday, i2/o9)

**③ Agent Orchestration 체계**
- Agent 간 Workflow 엔진
- MCP/A2A 기반 외부 툴 연계 모듈
- 외부 LLM 교체 가능한 모델 추상화 레이어

**④ 무인화 시범운영 시스템 (국내 1~2개)**
- 대상 시스템 선정, Agentic Workflow 구축
- 단계적 자율운영 시나리오 구현

**⑤ 성과측정 및 계약연계 체계**
- 업무 영역별 KPI/SLA 설계
- 성과 자동 집계 로직 및 대시보드
- ITO 비용 정산 연계 방안

**⑥ Agent 평가 및 변화관리 체계**
- Agent 품질 평가 프레임워크
- 지속 개선 프로세스 및 운영 매뉴얼


> **[근거]**
> - RFP 별첨 1, 별첨 2, 3.1~3.5 (①~⑥)
> - 회의록 12: AppZen 포털 수정·추가 개발 제안사 담당 (⑦)
> - 회의록 14 + 보완문서 G: 솔루션 특화 Agent (②)
> - 보완문서 A: 온보딩 간소화 (⑦)

## 3. 추진 방향 및 주요 내용

**핵심 논지:** 제안 범위 7가지 산출물을 관통하는 3대 추진 축을 제시한다. 이 축은 4장 세부 전략 전반에 일관되게 적용된다.

### 추진 축 1. Minimize — 기존 자산 최대 활용
- Gauss, 등 기존 자산 위에 구축하여 TCO 최소화
- 신규 인프라 구축을 전제하지 않는 설계
- 외부 LLM 교체 가능한 추상화 구조 (최신 모델·Tool 적용 용이)

> **[근거]**
> - RFP 3.1: "외부 모델 포함, 최신 모델/Tool 적용/교체가 용이한 구조"
> - 회의록 7: Gauss O 온프레미스, 2026 하반기 외부 모델 도입 준비
> - 보완문서 C: 기존 전자 인프라 재활용 원칙

### 추진 축 2. Connect — Agent·시스템·툴 연계
- MCP/A2A 기반 표준 연계 인터페이스
- 개발 단계 Agent 파이프라인 + 운영 단계 Agent Workflow
- 외부 툴(정적분석·형상관리·배포 등) MCP 연계

> **[근거]**
> - RFP 별첨 1 평가항목 "MCP Agent 연계"
> - RFP 3.1: "MCP/A2A 통신 모듈 개발, SonarQube/Git-Patch MCP 등 연동"
> - 회의록 11: MCP 대상 툴은 제안사 판단

### 추진 축 3. Measure — 성과 자동 축적 & 계약 연계
- 요청 접수부터 처리 완료까지 이력이 자동 축적되는 구조
- 축적 데이터 기반 KPI 자동 산출 → ITO 비용 정산 연계

> **[근거]**
> - RFP 별첨 1 평가항목 "성과측정 및 계약연계"
> - RFP 3.3: "ITO 비용정산 근거자료 자동산정체계 구축, SLA/KPI 설계"

## 4. 세부 추진 전략

### 4-1. Agent 고도화 및 신규 확대

**핵심 논지:** 기개발 Agent의 성숙도를 높이고, 업무 비중 가중 우선순위에 따라 운영·솔루션 특화 영역으로 확장한다.

**구성:**
- **(가) 기존 Agent 고도화** — 성숙도 평가 기반 우선순위 도출 후 고도화
- **(나) 운영 영역 신규 Agent** — 비중 가중 우선순위 (시스템 모니터링 29% → 문의대응 18% → 화면작동 9% → 기타)
- **(다) 솔루션 특화 Agent** — 단계적 접근 (Workday/SFDC → ABAP/i2·o9)

> **[근거]**
> - RFP 별첨 1 평가항목 "기개발 Agent 고도화", "신규 Agent 개발"
> - RFP 3.4 업무 비중표
> - RFP 3.1: "솔루션 특성 분석 기반 커스텀 및 특화 Agent 개발"
> - 회의록 10-2: "비중 × 목표수준" 평가 메커니즘
> - 회의록 14 + 보완문서 G: 솔루션 영역 단계적 접근 필요

---

### 4-2. Agent Orchestration & MCP/A2A 연계

**핵심 논지:** Agent가 단독 도구의 집합을 넘어 하나의 업무 흐름으로 작동하도록 Orchestration Layer를 구축한다.

**구성:**
- Orchestrator 설계 (Agent 라우팅, 상태관리, 예외처리)
- MCP 기반 외부 툴 연계 레이어
- 요청 → 처리 → 종료 E2E Workflow 구조
- 모델 추상화 레이어

> **[근거]**
> 
> - RFP 별첨 1 평가항목 "MCP Agent 연계"
> - RFP 3.2: "Orchestrator 기반 Agentic Workflow 설계 및 개발"
> - 회의록 11: MCP 대상 툴 자유 선택

---

### 4-3. 무인화 시범운영

**핵심 논지:** 4-1·4-2의 결과물을 국내 1~2개 시스템에 E2E 적용하여 AI 자율 운영의 실증 사례를 확보한다.

**구성:**

- 대상 시스템 선정 기준 및 후보 제시
- 단계적 무인화 시나리오
- Agentic Workflow 아키텍처
- 안정성 확보 방안 (Human-in-the-loop, Rollback, 감사로그)

> **[근거]**
> 
> - RFP 별첨 1 평가항목 "무인화 시범운영"
> - RFP 3.2: "운영인력 1명 미만 국내시스템 1~2개"
> - 회의록 8: 선정 기준 및 단계적 시나리오

---

### 4-4. 성과측정 및 계약 연계

**핵심 논지:** 업무 영역별 개선 효과를 다층적으로 측정하고, ITO 비용 정산에 자동 연계되는 체계를 구축한다.

**구성:**
- 업무 영역별 KPI 정의 (비중 가중치 반영)
- 다층 측정 체계
    - A/B 테스트 (기존 방식 보완)
    - Workflow 이력 기반 실적 자동 집계 (신규)
    - 사용자 피드백 기반 질적 평가
- 개선효과 → ITO 비용 정산 자동 산정 로직
- KPI 대시보드 및 정기 리포트
- 목표수준 제시

> **[근거]**
> - RFP 별첨 1 평가항목 "성과측정 및 계약연계"
> - RFP 3.3: "ITO 비용정산 근거자료 자동산정체계"
> - 회의록 9-2: A/B 테스트 한계, 대안 제안 시 최대 가점
> - 회의록 9-4: 목표수준 레인지 제시 허용
> - 회의록 10-1: 52개 액티비티 기반 비중 — 객관 지표

**구성:**

- 모델·프롬프트·연계 구성 변경 관리 체계
