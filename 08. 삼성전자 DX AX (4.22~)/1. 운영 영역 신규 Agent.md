## 제안
### 입출력 데이터를 공유하는 업무들을 하나의 Agent로 → 중복 파이프라인 제거 + 일관성 확보

| Agent              | 운영업무 항목 매핑          | 통합 근거                                                      | 핵심 역할                |
| ------------------ | ------------------- | ---------------------------------------------------------- | -------------------- |
| **운영 분석/보고 Agent** | 서비스 수준 관리 + 업무회의/보고 | **같은 운영 실적 데이터를 다른 형태(대시보드·보고서)로 출력**하는 관계                 | 운영 실적 데이터의 지능형 분석·보고 |
| **운영 지식 Agent**    | 이상상황 조치가이드 + 교육     | 기개발 이상상황 조치가이드는 **동일 지식 베이스를 다른 사용자 맥락(학습자·숙련자)에 제공**하는 관계 | 운영 지식의 축적·전달·대응 가이드  |
| **운영 개선 Agent**    | 업무지원                |                                                            | 이력 분석 기반 선제적 개선 발굴   |


### 과잉 자동화 지양 → 목표 수준의 근거, 기대관리 명확
| 영역           | 정의                           | Agent 역할            |     |
| ------------ | ---------------------------- | ------------------- | --- |
| **위임 영역**    | 반복·정형·규칙 기반 업무               | Agent가 완결           |     |
| **협업 영역**    | 해석·판단이 필요하나 초안·정보 제공이 유용한 업무 | Agent 초안 → 사람 검증·확정 |     |
| **사람 주도 영역** | 협상·관계·사업적 판단 영역              | Agent는 참고 데이터만 제공   |     |
### 외부 모델 교체 가능한 구조
LLM 의존 기능은 모델 추상화 레이어를 통해 구성하며, 특정 모델에 종속되지 않는 구조로 설계한다.





### 1. 운영 인사이트 Agent
운영 실적 데이터를 기반으로 SLA 측정, 운영 현황 분석, 보고 산출물 생성을 수행한다.
단일 데이터 원천 위에서 **대시보드·리포트·대화형 분석**이라는 세 가지 UX 모드를 통합 제공한다.
#### 대응 업무 영역 (RFP 비중표)
| 영역        | 비중     | 담당 범위                |     |
| --------- | ------ | -------------------- | --- |
| 서비스 수준 관리 | 3%     | SLA 측정·분석·보고         |     |
| 업무회의/보고   | 6%     | 정기·비정기 보고서 생성, 회의 지원 |     |
| **합계**    | **9%** |                      |     |



### 2. 운영 지식 Agent
운영 지식(매뉴얼·장애 대응 이력·릴리즈 노트)을 축적·구조화하여, 
실시간 장애 대응 가이드와 신규 운영자 온보딩·학습을 동시에 지원한다. 

#### 기개발 Agent와의 관계
**이상상황 조치가이드 Agent와 지식 베이스 공유** 본 과제에서 기개발 Agent의 고도화는 단순 성능 향상이 아니라 **운영 지식 Agent로의 발전**을 의미한다.
- 기개발 Agent의 기존 기능(장애 대응 가이드)은 유지·고도화됨
- 신규 기능(온보딩·학습·매뉴얼 검색)이 확장됨
- 하나의 지식 베이스를 공유하여 중복 제거

#### 대응 업무 영역 (RFP 비중표)
| 영역         | 비중     | 담당 범위                   |     |
| ---------- | ------ | ----------------------- | --- |
| 이상상황 조치가이드 | 2%     | 실시간 장애 대응 가이드 (기개발 고도화) |     |
| 교육         | 1%     | 온보딩·학습·의무교육 관리          |     |
| **합계**     | **3%** |                         |     |





### 3. 운영 개선 Agent
장애·문의·변경 이력을 분석하여 반복 패턴·근본원인을 도출하고 개선 과제를 능동적으로 발굴한다. 
운영 환경 구축·유지 가이드 생성을 포함한다.

#### 대응 업무 영역 (RFP 비중표)
| 영역     | 비중     | 담당 범위                    |     |
| ------ | ------ | ------------------------ | --- |
| 업무지원   | 2%     | 개선 발굴, 환경 구축 가이드, 신기능 검토 |     |
| **합계** | **2%** |                          |     |
