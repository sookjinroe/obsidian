**문의대응 (18%)**
- 사용자 문의 티켓 접수 (ITSM 시스템에서)
- 문의 내용 파악 후 단순 안내 vs 개발팀 배정 판단
- 단순 문의 직접 처리 ("비밀번호 초기화해주세요", "권한 추가해주세요" 등)
- 처리 불가 건은 담당 개발자에게 배정
- 처리 완료 후 사용자에게 결과 통보
- 미처리 티켓 현황 관리 및 독촉
- 자주 오는 문의 유형 파악 및 FAQ 관리

**데이터 추출 (2%)**
- 현업에서 "이 조건으로 데이터 뽑아줘" 요청 접수
- 조건 파악 후 SQL/BW 쿼리 직접 작성
- 결과 엑셀로 가공 후 전달
- 정기적으로 반복되는 추출 요청 처리
- 대용량 데이터는 일정 조율 후 처리

**시스템 모니터링 (29%)**
- 서버 CPU/메모리/디스크 사용률 주기적 확인 (임계치 초과 시 알람)
- 배치 Job 스케줄 성공/실패/지연 여부 확인
- DB 접속 세션 수, 쿼리 응답시간, Lock 발생 여부 확인
- 네트워크 트래픽, 포트 상태 확인
- 미들웨어(WAS) 상태 확인 (Tomcat, WebLogic 등)
- 알람 발생 시 담당자 연락 및 에스컬레이션
- 야간/주말 온콜 대응 (알람 받고 확인하는 업무 포함)
- 모니터링 결과 일/주/월 단위 정리

**화면작동 모니터링 (9%)**
- 주요 시스템 화면을 직접 접속해서 정상 여부 확인 (수동 클릭)
- 로그인 → 메인화면 → 핵심 메뉴 순서대로 열어보기
- 조회/저장/출력 등 핵심 기능 작동 여부 체크
- 화면 로딩 시간 측정
- 이상 발견 시 스크린샷 찍어 보고
- 점검 결과 체크리스트 작성 및 보고

**이상상황 조치가이드 (2%)**
- 장애 발생 시 과거 유사 사례 검색
- "이 오류 코드는 이렇게 해결한다" 가이드 제공
- 긴급 장애 시 조치 순서 안내
- 조치 후 결과 확인 및 재발 방지 방안 정리
- 장애 사후 보고서(Post-mortem) 작성

**업무회의/보고 (6%)**
- 주간 운영 현황 보고자료 작성 (장애건수, 처리현황 등)
- 월간 운영 보고서 작성
- 삼성전자 담당자와 정기 회의 참석
- 회의록 작성 및 공유
- 이슈/리스크 현황 정리 및 보고
- 임시 보고 요청 시 자료 작성

**서비스 수준 관리 (3%)**
- SLA 항목별 달성률 집계 (응답시간, 처리시간, 가용률 등)
- 미달 항목 원인 분석
- 월별 SLA 보고서 작성
- 개선 계획 수립 및 보고
- 계약 상 패널티 여부 확인

**업무지원 (2%)**
- 신규 운영자 PC/계정/접속환경 셋업
- 운영 매뉴얼/가이드 문서 관리 및 업데이트
- 운영 툴 라이선스/버전 관리
- 개선 아이디어 발굴 및 검토 보고
- 타 팀 요청 시 운영 관련 지원

**교육 (1%)** → 대상이 내부 운영자인지 시스템 사용하는 현업인지?
- 신규 운영자 온보딩 교육
- 시스템 변경 시 현업 사용자 교육 자료 작성
- 교육 진행 및 결과 보고
- 사내 의무 교육 이수 관리
 **ITO 운영인력(외부인력)이 받는 교육**
- 삼성전자 보안 교육 의무 이수
- 시스템 변경 시 운영자 대상 교육 수강완저
- 신규 투입 인력 온보딩 교육
