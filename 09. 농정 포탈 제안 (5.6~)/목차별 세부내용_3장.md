## 3장. 공통 자산 관리 (한 슬라이드)

### 1단계 — 응답할 RFP 요건군

| RFP 항목 | 내용                         |
| ------ | -------------------------- |
| 5)-1   | 산출물을 자산화하여 통합 관리할 수 있는 체계  |
| 5)-2   | 표준화된 제안 목차 + 지속적 개선 가능한 관리 |
| 5)-3   | 변경이력, 유형별 관리 등 체계적 자산관리    |
| 9)-1   | 사업유형·규모·프로젝트 특성 반영한 자산 등록  |
| 9)-2   | 메타데이터 기반 관리체계, 데이터 일관성·정합성 |

→ **본질**: 자산 라이브러리에 4유형 자산이 두 경로로 들어오고, 메타데이터·이력·버전으로 관리된다.

---

### 2단계 — 본문 컨텐츠

**자산 등록 흐름 (다이어그램으로 표현할 핵심)**

- 운영자가 표준 목차·제안 템플릿을 라이브러리에 직접 등록·갱신
- 프로젝트 제안룸의 확정 산출물은 운영자 검토를 거쳐 최종 산출물로 자산화
- 자산화된 최종 산출물 중 우수성을 인정받은 산출물은 우수 제안서로 분류

**메타데이터로 검색·재활용 기반 마련** 자산 등록 시 특성을 메타데이터로 입력하여 다양한 조건으로 검색·재활용이 가능합니다. 모든 자산이 동일한 메타데이터 스키마를 따르도록 하여 검색 결과의 일관성을 확보합니다.

**변경이력·버전 관리로 자산 신뢰성 유지** 자산 등록·수정·삭제 이력을 자산 단위로 기록하여 변경 추적이 가능합니다. 자산 수정 시 새 버전이 등록되어 이전 버전 조회까지 지원합니다.

---

### 3단계 — 형식 결정

**a.** 텍스트로 명료한가 → 자산 등록 흐름은 텍스트만으로는 두 경로가 잘 안 보임. 다이어그램이 효과적. **b.** 시각 자료 가치 → 4유형이 어디서 어떻게 들어오는지 흐름 시각화 가치 큼. **c.** 형태 → 다이어그램 (자산 등록 흐름) + 텍스트 (메타데이터·이력) **d.** 슬라이드 최종 구성
