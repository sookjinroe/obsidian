
## 화면 리스트 도출 원칙

플로우 단계가 화면이 되는 게 아니라, **같은 맥락의 단계들을 묶어서 하나의 화면**으로 만듭니다. 묶는 기준은:

- 사용자가 한 자리에서 연속적으로 하는 작업인가
- 페이지 이동 없이 다음 단계로 자연스럽게 흘러가는가
- 상태(맥락)를 잃으면 안 되는가

---

## 화면 리스트

### 화면 1. 홈

**담당 플로우**: ① 진입, ② 커넥터·입력 자산 상태 확인

**구성 영역**

- 최근 실행 요약 (최근 잡 몇 개, 진행 상태)
- 커넥터 상태 카드 (DB / 코드 저장소)
- 입력 자산 상태 카드 (용어집)
- "새 실행" 진입점

**역할**: 첫 진입 시 시스템 상태 파악 + 다음 행동 진입점

---

### 화면 2. 커넥터 관리 (옵션)

**담당 플로우**: ② 커넥터 추가·수정 (필요 시)

**구성 영역**

- DB 커넥터 목록 + 추가
- 코드 저장소 커넥터 목록 + 추가
- 연결 테스트

**역할**: 설정 화면. 자주 안 들어감.

**1차 프로토 판단**: 가짜 데이터로 충분하다면 **이 화면은 스킵 가능**. 홈에 상태 표시만 있으면 됨. 데모에서 "이미 연결돼 있다"고 가정.

---

### 화면 3. 입력 자산 관리 (옵션)

**담당 플로우**: ② 용어집 업로드·편집 (필요 시)

**구성 영역**

- 용어집 업로드 / 동기화 / 직접 편집
- 등록 term 수, 최근 갱신일

**역할**: 설정 화면.

**1차 프로토 판단**: **스킵 가능**. 홈에 상태 표시만 있으면 됨. 데모에서 "이미 용어집이 있다"고 가정.

---

### 화면 4. 실행 생성

**담당 플로우**: ③ 실행 대상 선택, ④ 실행 트리거

**구성 영역**

- 실행 범위 선택 (시스템 / 테이블 / 컬럼) — 단계별 선택 UI
- Description 존재 여부 필터
- "Description 생성" 버튼
- 실행 직후 잡 리스트로 자동 이동

**역할**: 실행 시작점. 데모의 도입부.

---

### 화면 5. 잡 리스트

**담당 플로우**: ⑤ 잡 리스트 진입, ⑥ 잡 선택

**구성 영역**

- 탭: 실행중 / 대기 / 완료 / 실패
- 잡 row: 테이블명 / 시스템 / 시작시간 / 진행률
- 정렬·검색
- 잡 클릭 → 잡 상세로 이동

**역할**: 전체 잡 관제. 데모에서 "여러 잡이 병렬로 돈다"는 인상 전달.

---

### 화면 6. 잡 상세 (★ 데모 핵심 화면)

**담당 플로우**: ⑦ 잡 상세 진입, ⑧ 실시간 스트리밍, ⑨ B2-lite 메시지, ⑩ 컬럼별 완성, ⑪ 잡 완료, ⑫ 결과 목록 탐색, ⑬ 필터링·검색, ⑭ 컬럼 상세, ⑮ 판정

**구성 영역**

- 상단: 테이블 정보 + 진행률 + 잡 상태 (실행중/완료) + 결과 요약 카드
- 좌측: 컬럼 리스트
    - 컬럼명 + 처리 상태 + Confidence 배지 + 출처 배지
    - 진행중 컬럼 자동 하이라이트
    - Confidence 필터, 컬럼명 검색
- 우측: 선택된 컬럼의 상세
    - 진행중 컬럼: 실시간 추론 스트리밍 + B2-lite 메시지
    - 완료 컬럼: 결과 + 출처 역추적 + 추론 기록 + 담당자·사용처 + 판정 액션
- 사이드 (옵션): 용어집 보강 후보 패널

**역할**: 데모 핵심. 7분 + 10분 = **총 17분의 시연이 이 화면에서 일어남**. 전체 시연 시간의 60%.

---

### 화면 7. 반출

**담당 플로우**: ⑯ 반출 대상 선택, ⑰ 반출 방식 선택, ⑱ 완료

**구성 영역**

- 반출 대상 선택 (승인된 것만 / 전체)
- 반출 방식 선택 (다운로드 / 카탈로그 반영)
- 완료 안내

**역할**: 결과 내보내기. 데모에선 1분짜리 마무리.

**1차 프로토 판단**: **버튼 수준만 구현 가능**. 모달 하나 띄워서 "다운로드 시작" 또는 "카탈로그 반영 완료" 메시지만 보여줘도 충분. 별도 화면이 아니라 **잡 상세에 버튼만 두는** 방식도 가능.

---
### 화면 리스트 (확정)

|#|화면|우선순위|구현 수준|
|---|---|---|---|
|1|홈|필수|정상 구현|
|2|커넥터 관리|보조|가짜 데이터|
|3|입력 자산 관리|보조|가짜 데이터|
|4|실행 생성|필수|정상 구현|
|5|잡 리스트|필수|정상 구현|
|6|잡 상세 ★|핵심|완전 구현|
|7|반출|—|모달로 처리 (별도 화면 X)|

### 글로벌 헤더 (모든 화면 상단 공통)

```
[로고]  [홈] [잡 리스트] [커넥터] [입력 자산]      [+ 새 실행]
```

**구성**

- 좌측: 로고 + 주요 메뉴 (홈 / 잡 리스트 / 커넥터 / 입력 자산)
- 우측: "새 실행" 진입 버튼 (어느 화면에서든 새 잡 생성 가능)

**효과**

- 어느 화면에서든 새 실행 시작 가능
- 좌측 메뉴로 화면 간 이동 자유로움
- 데모 중 시연자가 자연스럽게 화면 전환 가능

### 화면 간 전환 플로우 (업데이트)

```
[글로벌 헤더 항상 존재]

홈
  ├─ 새 실행 (헤더) → 실행 생성
  ├─ 헤더 메뉴 → 잡 리스트 / 커넥터 / 입력 자산
  └─ 잡 카드 클릭 → 잡 상세

실행 생성
  └─ 실행 트리거 → 잡 리스트 (자동 이동)

잡 리스트
  └─ 잡 클릭 → 잡 상세

잡 상세 (★)
  ├─ 좌측 컬럼 클릭 → 우측 패널 전환
  ├─ 헤더 뒤로/홈 → 다른 화면
  └─ "반출" 버튼 → 반출 모달

커넥터 / 입력 자산
  └─ 가짜 데이터 표시
```

## 데모 동선과 화면 매핑

```
30분 데모:
  홈 진입            [홈]              1분
  실행 범위 선택      [실행 생성]        1분
  잡 리스트          [잡 리스트]        1분
  실시간 추론 관찰    [잡 상세] (실행중)  7분
  B2-lite 노출       [잡 상세]
  잡 완료            [잡 상세] (완료)
  Confidence 검토    [잡 상세]          10분
  반출 시연          반출 모달          1분
  포지셔닝·Q&A                          7분
```
