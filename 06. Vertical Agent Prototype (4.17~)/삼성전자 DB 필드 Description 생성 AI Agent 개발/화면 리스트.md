# 화면 리스트

---

## 도출 원칙

플로우 단계가 화면이 되는 게 아니라, **같은 맥락의 단계들을 묶어서 하나의 화면**으로 만든다. 묶는 기준은:

- 사용자가 한 자리에서 연속적으로 하는 작업인가
- 페이지 이동 없이 다음 단계로 자연스럽게 흘러가는가
- 상태(맥락)를 잃으면 안 되는가

---

## 화면 목록

### 화면 1. 홈

**담당 플로우**: ① 진입, ② 커넥터·입력 자산 상태 확인

**구성 영역**

- 최근 실행 요약 (최근 잡 목록, 상태)
- 커넥터 상태 카드 (DB / 코드 저장소)
- 입력 자산 상태 카드 (용어집 — term 수, 갱신일, 보강 후보 건수)
- "새 실행" 진입점

**역할**: 첫 진입 시 시스템 상태 파악 + 다음 행동 진입점

---

### 화면 2. 커넥터 관리

**담당 플로우**: ② 커넥터 추가·수정 (필요 시)

**구성 영역**

- DB 커넥터 목록 + 연결 상태
- 코드 저장소 커넥터 목록 + 연결 상태
- 연결 테스트

**1차 구현 수준**: 가짜 데이터. 데모에서 "이미 연결돼 있다"고 가정.

---

### 화면 3. 입력 자산 관리

**담당 플로우**: ② 용어집 업로드·편집 (필요 시)

**구성 영역**

- 용어집 업로드 / 카탈로그 동기화 / 직접 편집
- 현재 용어집 현황 (등록 term 수, 갱신일, 보강 후보 대기 건수)
- 보강 후보 검토 버튼 (B2-lite 연결 — 2차 실제 구현)

**1차 구현 수준**: 가짜 데이터. 용어집이 이미 구축되어 있다고 가정.

---

### 화면 4. 실행 생성

**담당 플로우**: ③ 실행 대상 선택, ④ 실행 트리거

**구성 영역**

- 실행 범위 선택 (시스템 / 테이블 / 컬럼) — 칩 선택 UI
- 시스템·테이블 선택 드롭다운
- Description 존재 여부 필터 (없는 것만 / 전체)
- "Description 생성" 버튼 → 잡 리스트로 자동 이동

**역할**: 실행 시작점. 데모의 도입부.

---

### 화면 5. 잡 리스트

**담당 플로우**: ⑤ 잡 리스트 진입, ⑥ 잡 선택

**구성 영역**

- 탭: 전체 / 실행중 / 대기 / 완료 / 실패
- 잡 row: 테이블명 / 시스템 / 시작시간 / 진행률 바 / 상태 배지
- 정렬·검색
- 잡 클릭 → 잡 상세로 이동

**역할**: 전체 잡 관제. 데모에서 "여러 잡이 병렬로 돈다"는 인상 전달.

---

### 화면 6. 잡 상세 ★ (데모 핵심 화면)

**담당 플로우**: ⑦~⑮ 전체 (실행 관찰 + 결과 검토 + 판정)

**구성 영역**

상단 바

- 테이블명 + 시스템 + 잡 상태 (실행중 / 완료)
- 진행률 카운터 (N / 전체)
- Confidence 분포 pills (High N / Med N / Low N / 침묵 N)
- 반출 버튼 (완료 시 활성)

좌측 패널 — 컬럼 리스트 (268px)

- 컬럼명 검색
- Confidence 필터 (High / Med / Low 토글)
- 컬럼 row: 컬럼명 + Confidence 배지 + 출처 배지
- 진행중 컬럼: 스피너 + 파란 왼쪽 선
- 완료 컬럼: 클릭 가능
- 대기 컬럼: 흐리게 표시

우측 패널 — 컬럼 상세 (가변)

실행중 컬럼 선택 시:

- 실시간 추론 스트리밍 (자동 시작)
- 단계별 상태 메시지 + 결과
- B2-lite 용어집 gap 메시지 끼어듦

완료 컬럼 선택 시:

- Description (한글 + 영문)
- Confidence 수준
- 출처 역추적 (구성 요소별 — 어느 term/소스에서 왔는지)
- 추론 과정 기록 (레벨별 성공/실패)
- 담당자·사용처 (mock)

하단 액션 바

- 선택된 컬럼명 컨텍스트 표시
- 판정 버튼: 승인 / 반려 / 수정 / 에스컬레이션
- 실행중 상태: 판정 버튼 비활성 + "잡 완료 후 판정 가능" 안내

사이드 (B2-lite)

- 용어집 보강 후보 패널 접근 (mock)

**역할**: 데모 핵심. 30분 시연 중 17분이 이 화면에서 진행됨.

---

### 화면 7. 반출 (모달)

**담당 플로우**: ⑯ 반출 대상 선택, ⑰ 반출 방식 선택, ⑱ 완료

**구성 영역**

- 반출 대상 선택 (승인된 것만 / 전체)
- 반출 방식 선택 (JSON / CSV / 카탈로그 반영)
- 확인 버튼 (방식에 따라 "다운로드" / "카탈로그 반영"으로 동적 변경)

**구현 방식**: 잡 상세 화면 내 모달로 처리. 별도 페이지 없음.

## 화면 우선순위 요약

|#|화면|우선순위|구현 수준|
|---|---|---|---|
|1|홈|필수|정상 구현|
|2|커넥터 관리|보조|가짜 데이터|
|3|입력 자산 관리|보조|가짜 데이터|
|4|실행 생성|필수|정상 구현|
|5|잡 리스트|필수|정상 구현|
|6|잡 상세 ★|핵심|완전 구현|
|7|반출|—|모달로 처리|

---

## 글로벌 헤더 (모든 화면 공통)

```
[field.agent]  [홈] [잡 리스트] [커넥터] [입력 자산]      [+ 새 실행]
```

- 좌측: 로고 + 주요 메뉴 (홈 / 잡 리스트 / 커넥터 / 입력 자산)
- 우측: "새 실행" 버튼 (어느 화면에서든 새 잡 생성 가능)

---

## 화면 간 전환 플로우

```
[글로벌 헤더 항상 존재]

홈
  ├─ 새 실행 (헤더) → 실행 생성
  ├─ 헤더 메뉴 → 잡 리스트 / 커넥터 / 입력 자산
  └─ 잡 카드 클릭 → 잡 상세

실행 생성
  └─ 실행 트리거 → 잡 리스트 (자동 이동, 새 잡 상단에 추가됨)

잡 리스트
  └─ 잡 클릭 → 잡 상세

잡 상세 ★
  ├─ 좌측 컬럼 클릭 → 우측 패널 전환 (페이지 이동 없음)
  ├─ 헤더 메뉴 → 다른 화면
  └─ "반출" 버튼 → 반출 모달

커넥터 / 입력 자산
  └─ 가짜 데이터 표시
```

## 데모 동선과 화면 매핑

```
30분 데모:
  홈 진입              [홈]               1분
  실행 범위 선택        [실행 생성]         1분
  잡 리스트            [잡 리스트]         1분
  실시간 추론 관찰      [잡 상세] (실행중)   7분
  B2-lite 노출         [잡 상세]
  잡 완료              [잡 상세] (완료)
  Confidence 검토       [잡 상세]          10분
  반출 시연            반출 모달            1분
  포지셔닝·Q&A                             7분
```

데모의 **17분이 잡 상세 화면 하나에서 일어남.**
