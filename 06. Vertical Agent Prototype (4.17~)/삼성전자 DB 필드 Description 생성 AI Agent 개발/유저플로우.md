## 플로우 1 — 실행 준비

```
① 진입
   - 홈 화면 접근

② 커넥터·입력 자산 상태 확인
   - DB 연결 상태
   - 코드 저장소 연결 상태
   - 용어집 상태 (등록 term 수, 최근 갱신일)

③ 실행 대상 선택
   - 실행 범위: 시스템 / 테이블 / 컬럼
   - Description 존재 여부 필터: 없는 것만 / 전체(있는 것 포함)

④ 실행 트리거
   - "Description 생성" 버튼
   - 시스템 / 다중 테이블 선택 시 → 테이블 단위 잡 N개가 큐에 들어감
   - 단일 컬럼 선택 시 → 컬럼 한 개짜리 잡 생성
```

---

## 플로우 2 — 잡 관리

```
⑤ 잡 리스트 진입
   - 탭: 실행중 / 대기 / 완료 / 실패
   - 잡별 정보: 테이블명·시스템·시작시간·진행률
   - 정렬·검색 가능

⑥ 잡 선택
   - 실행중 잡: 진행 상황 관찰
   - 완료 잡: 결과 검토
   - 나갔다 돌아와도 현재 상태 이어서 표시
```

---

## 플로우 3 — 실행 관찰 (데모 핵심)

```
⑦ 잡 상세 진입
   - 진입 시 자동으로 현재 처리 중인 컬럼의 스트리밍이 우측 패널에 보임
   - 좌측: 컬럼 리스트 (완료된 것 + 진행중 + 대기 모두 표시)
   - 진행중 컬럼은 자동 하이라이트

⑧ 실시간 추론 스트리밍 관찰 (우측 패널)
   - 추론 단계별 상태 메시지 (자연어):
     "다른 시스템에서 같은 컬럼 확인 중..."      (L0)
     "용어집을 조회해 의미를 조립하는 중..."    (L1)
     "스키마·샘플값으로 추론하는 중..."         (L2)
     "소스코드에서 라벨·Enum 찾는 중..."       (L3)
     "판단 불가 — 단서 부족"                   (L-1)

⑨ B2-lite 용어집 gap 메시지 (스트리밍 중 끼어듦, mock)
   - "용어집에 'pkg' 미등록 → 후보로 등록 중..."
   - "소스코드에서 'package' 확장형 발견"
   - "용어집 보강 후보 검토 대기 (3건)"

⑩ 컬럼별 완성 → 자동 다음 컬럼으로 진행
   - Description·Confidence·출처 생성
   - 좌측 컬럼 리스트의 해당 row 상태 업데이트

⑪ 잡 완료
   - 결과 요약 (성공 N / 검토필요 M / 침묵 K)
   - 판정 버튼 활성화
```

## 플로우 4 — 결과 검토 (잡 완료 후)

```
⑫ 결과 목록 탐색 (잡 상세 화면 내)
   - 좌측 컬럼 리스트
   - Confidence 배지로 한눈에 구분 (High / Medium / Low)
   - 출처 배지 (재활용 / 용어집 / 소스코드 / 샘플값)

⑬ 필터링·검색
   - Confidence 필터
   - 컬럼명 검색

⑭ 컬럼 클릭 → 우측 패널에 상세 표시
   - 완료 컬럼: 결과 + 추론 기록 조회 (스트리밍 아님)
   - Description 본문
   - Confidence + 출처 역추적 (구성 요소별)
   - 추론 과정 기록 (어느 레벨에서 성공/실패했는지)
   - 담당자·사용처 (mock)

⑮ 판정 액션
   - 승인 / 반려 / 수정 / 에스컬레이션
   - 반려: 상태만 "반려됨"으로 표시 (재처리는 별도 실행)
   - 에스컬레이션: UI만 동작, 실제 알림은 생략
```

## 플로우 5 — 반출

```
⑯ 반출 대상 선택
   - 승인된 것만 / 전체

⑰ 반출 방식 선택
   - 다운로드 (JSON/CSV)
   - 카탈로그 반영 버튼 (실제 연동은 옵션, 시연은 mock)

⑱ 완료
```

## 분기 지점 / 결정 사항

|항목|결정|
|---|---|
|실행중 판정|불가. 완료 후 판정 가능. 잡 리스트는 탭으로 구분, 잡 상세 화면은 공유|
|출처 필터|1차 제거. Confidence 필터만 유지. 출처는 컬럼 리스트 배지로 표시|
|스트리밍 이탈 후 복귀|완료 컬럼은 결과 조회, 진행중 컬럼만 실시간 스트리밍|
|추론 경로 조회|"재생"이 아니라 "사후 조회". LangGraph state를 구조화된 JSON으로 저장|
|반려 동작|상태만 "반려됨"으로 표시. 재처리는 별도 실행으로|
|에스컬레이션|UI만 있고 실제 알림 동작 없음|
|실행중 관찰 모드|잡 상세 진입 시 자동으로 진행중 컬럼 스트리밍이 우측에 표시. 좌측 리스트에서 다른 컬럼 클릭 시 전환|
